PORTFOLIO CHECKLIST — ULISES.IO
https://ulises.io/en/portfolio-projects-that-strengthen-your-developer-resume

[ ] I can explain the problem and who the project helps.
[ ] The deployed demo works in a private browser window.
[ ] The README includes the goal, screenshots and a demo link.
[ ] Setup instructions let someone run the project.
[ ] An example environment file contains no secrets.
[ ] No credentials or personal data are published.
[ ] I can explain my technical choices.
[ ] I documented a real obstacle and how I solved it.
[ ] I reviewed errors, empty states and mobile usability.
[ ] I verified the main workflows and explained how to check them.
[ ] I distinguish my work from tutorial or AI-generated code.
[ ] My resume links to a finished, accessible project.

Practice explaining: I built ____ for ____. I chose ____ because ____.
The hardest problem was ____; I solved it by ____. Next time I would change ____.
