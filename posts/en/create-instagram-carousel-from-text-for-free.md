## Plan the sequence before choosing colors

A carousel does not need ten slides to be complete. Start with a question you can answer and decide what readers should understand when they finish.

To explain a programming decision, you could use this sequence:

| Slide | Purpose | Example |
| --- | --- | --- |
| 1 | Introduce the problem | My application saved duplicate expenses |
| 2 | Explain the cause | Repeated submission created another operation |
| 3 | Show the decision | I added a way to identify the same attempt |
| 4 | Describe verification | I checked what happened when submitting twice |
| 5 | Suggest the next step | Test this workflow in your next project |

This is an editorial example, not a story of real results. Replace each line with something you can demonstrate in your own application.

## Write text the editor understands

The first line of each block becomes its title, and the rest becomes its body. Separate slides with a line containing only three dashes: `---`.

For example, write “A concrete problem” as the title, add a short explanation below, then the separator and “A decision you can defend” as the next title. Putting every paragraph into one block will not magically create a sequence of ideas.

The tool supports **one to ten slides**. That is an editor limit, not a statement about Instagram’s maximum. If your explanation needs more, simplify the argument or split it into two pieces that each make sense on their own.

## Cut words before shrinking the text

If a slide cannot be exported because it contains too much text, simplify its content. The editor does not need all the technical context in one image.

Replace “In the context of the development process for this application I decided to implement…” with a concrete statement: “I chose this solution because…”. If the explanation is still long, turn it into two ideas and make sure the second slide remains understandable.

Check contrast too. A beautiful brand color can be difficult to read on another brand color. The tool warns when text and background have low contrast; also inspect the result at phone size.
