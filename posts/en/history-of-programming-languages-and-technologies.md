Programming has come a long way. Work that once involved physical switches and punched cards can now be expressed through programming languages and deployed on cloud platforms.

Understanding that history helps explain why modern tools look the way they do. This guide follows the evolution of programming from Ada Lovelace and assembly language through high-level languages, structured programming, the web, mobile applications, cloud computing and AI.

## The beginnings: when programming meant configuring hardware

Before programming languages took their modern form, instructing a machine could mean physically changing its configuration.

### Ada Lovelace and the Analytical Engine

In the nineteenth century, Ada Lovelace recognized possibilities in Charles Babbage’s proposed Analytical Engine that went beyond numerical calculation. Her notes published in 1843 included a procedure for calculating Bernoulli numbers with the machine. This is why she is often called the first programmer; it does not mean she invented algorithms, which existed much earlier.

Lovelace also considered whether a machine could manipulate symbols and compose music. Her contribution helped articulate the distinction between a calculating device and a more general computing machine. The [Computer History Museum’s account](https://www.computerhistory.org/babbage/adalovelace/) also discusses the debate about her close collaboration with Babbage.

### Vacuum tubes and assembly language: the 1940s and 1950s

Early electronic computers such as ENIAC could require manual wiring to set up a task. Stored-program designs later made it possible to keep instructions in memory.

Assembly language replaced raw binary instructions with mnemonics: short names for machine operations. This made code easier to write and inspect, but it remained closely tied to the architecture of the particular computer.

## High-level languages: the 1950s through the 1970s

Higher-level languages let programmers express more of their intent without specifying every machine instruction.

* **FORTRAN, released in 1957:** Developed at IBM for scientific calculation, it became an early widely adopted high-level language.
* **COBOL, developed in 1959:** Designed for business computing, it helped bring software into financial and administrative systems.
* **C, developed in the early 1970s:** Dennis Ritchie created C at Bell Labs as part of the development of Unix. It influenced the syntax and implementation of many later languages.

## Structured programming: bringing order to control flow

Before object-oriented programming became popular, structured programming changed how developers organized instructions.

Programs that relied heavily on `GOTO` jumps could become difficult to follow, debug and maintain. In 1968, Edsger Dijkstra’s letter “Go To Statement Considered Harmful” became an influential contribution to the debate about control flow.

Structured programming emphasizes familiar building blocks:

1. **Sequence:** execute instructions in order.
2. **Selection:** choose a path with constructs such as `if`, `else` or `switch`.
3. **Iteration:** repeat work with loops such as `for` and `while`.

Languages including ALGOL and Pascal, introduced by Niklaus Wirth in 1970, helped establish structured programming in education and practice. An enduring lesson was that software should be readable by people as well as executable by machines.

These ideas remain part of everyday programming. You can practice them in the [programming logic and data structures guide](/en/programming-logic-and-data-structures-guide).

## Object-oriented programming and larger applications

As applications grew, developers needed ways to organize data and behavior into manageable units. Object-oriented programming became an important part of that work during the 1980s and 1990s.

* **C++:** Bjarne Stroustrup developed C++ from work extending C with classes, helping make object-oriented techniques widely available.
* **Java, released in 1995:** Its virtual machine and portability goals made it influential in enterprise software.
* **Python, first released in 1991:** Guido van Rossum emphasized readable code. Python later became widely used for automation, data analysis and AI, as well as other applications.

## The web changes software delivery

From the mid-1990s onward, the web made the browser an increasingly important place to run software.

1. **HTML and CSS** provided the structure and presentation of web pages. They are essential web technologies, although they are not general-purpose programming languages.
2. **JavaScript**, created by Brendan Eich in 1995, brought programmable behavior to browsers. Its ecosystem later expanded to servers and other environments, including through Node.js.
3. **PHP** helped developers build dynamic websites and contributed to the growth of platforms such as WordPress.

The web changed both what developers built and how people accessed it. Applications no longer had to be distributed solely through physical media or installed separately on every device.

## Mobile applications and cloud computing

During the 2010s, smartphones made mobile application development central to many products. Objective-C and Swift were important in Apple’s ecosystem, while Java and later Kotlin played major roles in Android development.

At the same time, cloud platforms changed deployment. Developers could provision infrastructure through services such as AWS, Azure and Google Cloud rather than managing every physical server themselves. Containers and serverless services added more options for packaging and operating applications.

## AI-assisted programming

Generative AI offers another way to express intent: describe a task in natural language and have a model propose code. Autocomplete tools and coding assistants can support implementation, explanation and debugging.

That does not remove the need to define requirements, check correctness, protect data or maintain the resulting system. Earlier changes in abstraction expanded what programmers could build, but historical patterns alone cannot predict how every job will change.

## Frequently asked questions

**Who was the first programmer?**

Ada Lovelace is often given that recognition because of her 1843 notes about Babbage’s Analytical Engine. Her published procedure is historically important, although the details of her collaboration with Babbage remain a subject of discussion.

**What was the first high-level programming language?**

FORTRAN, commercially released by IBM in 1957, is commonly described as the first widely adopted high-level language. Earlier proposals and experiments existed, so “first” needs that qualification.

**What is structured programming?**

It is an approach to organizing control flow around sequence, selection and iteration rather than relying on unrestricted jumps. It helped make programs easier to understand and maintain.

**Why learn the history of programming?**

Programming tools and paradigms developed in response to specific problems. Understanding that context helps you evaluate the trade-offs in modern tools instead of treating every new technology as an isolated trend.

## What comes next?

Many developments in programming have increased the level of abstraction available to developers. We can express more complex behavior without managing every low-level detail ourselves.

That progress changes the work rather than making understanding irrelevant. The history of programming offers useful context for choosing tools, learning fundamentals and evaluating what a new technology can actually do.
